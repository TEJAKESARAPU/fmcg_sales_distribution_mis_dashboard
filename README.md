The dashboard converts raw transactional data into actionable business insights, enabling management to monitor KPIs and make data-driven decisions.

# 🚀 Project Overview

This project simulates a real-world **Management Information System (MIS)** used in FMCG organizations to monitor daily sales and operational performance.

The dashboard provides a single view of business performance through:

- 📈 Sales Analytics
- 🎯 Target vs Achievement
- 🌍 Regional Performance
- 🛒 Product Performance
- 📦 Inventory Monitoring
- 💰 Pending Collections
- 📊 Executive KPIs

---

# 🎯 Business Objective

The dashboard helps answer important business questions such as:

✅ Are sales targets being achieved?

✅ Which region is performing the best?

✅ Which product contributes the highest revenue?

✅ Which category drives maximum sales?

✅ How are sales trending month-over-month?

✅ Which products require stock replenishment?

✅ How much payment is pending from distributors?
